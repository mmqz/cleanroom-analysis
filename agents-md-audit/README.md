## 被审计的到底是什么

`AGENTS-EN.md` 是一份英文 Markdown 文档，遵循 [agents.md 惯例](https://agents.md)（OpenAI Codex CLI、Claude Code、Cursor、Vercel open-agents 等代理宿主都会自动读取仓库根目录的 `AGENTS.md` 作为代理指令）。它包含 **Purpose + 23 个编号章节 + Final Rule**，全部内容是行为规范（policy），不含任何可执行代码。

## 关键发现速览

1. **字符层零命中**：零宽字符、Bidi 控制符（Trojan Source）、Unicode Tag 隐藏文本、同形字、ANSI 转义、Base64/Hex 载荷、控制字符——全部为 NONE；非 ASCII 字符仅有 47 个 `→`、7 个 `—`、4 个智能引号，均为排版符号。逐节熵值 4.0–4.8 bits/char，均匀无异常。
2. **全文档仅 6 条真实 shell 命令，全部是 git 只读命令**（`status` / `branch --show-current` / `remote -v` / `diff --stat` / `diff` / `status`）。唯一的网络行为是"验证后 push"，且配有反欺骗条款：“不得无证据声称 push 成功”。
3. **59 条指令句全部面向软件工程纪律**：无凭据读取、无数据外传、无任意命令执行、无 "ignore previous instructions" 类注入。
4. **唯一削弱人工监督的条款是 §10 One-Phase YOLO Execution**（整阶段连续执行不逐步确认），但有 5 条硬暂停条件兜底（破坏性操作、凭据、真歧义、范围变更、危及无关工作）。
5. **7 个外部仓库全部验证为真实、活跃、合法**（2026-08 至 2026-10 均有提交）；扫描命中的"注入模式"经核查全部为防御性代码（vercel 的 bash 工具凭据黑名单、PracticalSwan 的 skillguard 注入扫描器、bun.sh 官方安装脚本）。
6. **与 open-agents 自带的 AGENTS.md 无派生关系**（共同行均为短语）：被审计文件是“跨项目代理宪法”，后者是“单项目工程指南”，属同一惯例的两个层级。
