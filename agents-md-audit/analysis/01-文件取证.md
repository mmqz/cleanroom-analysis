# 01 · 文件取证：身份鉴定与隐藏载荷排除

> 目标：确定文件的真实身份，并排除一切"休眠未触发"的字符层恶意载荷。
> 工具：`tools/agents_forensic_scan.py` · 原始输出：`evidence/forensic-scan.json`

## 1. 文件身份

| 属性 | 值 | 判读 |
|---|---|---|
| 类型 | UTF-8 纯文本（Markdown） | **不是二进制可执行文件**，不存在机器码层面的"未触发行为" |
| 大小 / 行数 | 17,482 字节 / 707 行 | 中等体量的策略文档 |
| SHA-256 | `c2576fe6d2b8c70e...`（完整值见 evidence） | 可作为引用锚点 |
| MD5 | `5d6a4e...`（见 evidence） | — |
| BOM | 无 | 干净的 UTF-8 |
| 行尾 | 纯 LF（0 个 CRLF、0 个孤立 CR） | Unix 风格，无跨平台混淆 |
| 非 ASCII | 仅 `→`(47)、`—`(7)、`“”`(4) | 全部为排版符号，合法 |

**结论 1**：所谓"恶意行为可能隐藏在软件内部未触发"的前提需要修正——该文件不含任何机器码。它唯一能"触发行为"的方式是被一个 AI 代理宿主当作指令读入。因此本次审计的重点是：**休眠的提示注入、隐藏指令字符、以及会在未来某个条件下被激活的条款**。

## 4. 逐节熵值分析

对各章节正文（剔除 Markdown 结构符号后）计算 Shannon 熵，全部落在 **4.0–4.8 bits/char** 区间——这是正常英文技术文本的典型范围。没有任何章节出现高熵异常（加密/压缩数据通常 >6.5）或可疑的低熵重复（填充/隐写通常 <2.5 且集中在局部）。

熵值最高的三节：`5. Classify the Work`（5.10，因为是大写枚举清单）、`Status`（4.70）、`21. Durable Phase State`（4.52）；最低的为 §23 内嵌模板字段（2.2–2.8，模板占位文本，符合预期）。**无异常**。

## 5. 取证小结

- 文件是一份**干净的、可直接人工通读的英文策略文档**；不存在任何字符层隐藏内容，"用工具处理到可读"这一步的实际结论是：文件本来就是完全可读的，且没有第二层隐藏语义。
- 若该文件有任何风险，只能来自**明文写出的条款本身**（例如削弱人工监督、引入外部依赖）——这部分转入 04-安全审计 的行为面分析。
