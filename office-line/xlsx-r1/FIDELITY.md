# 已有工作簿修改最小技术验证——保真对比与丢失矩阵（t10-c）

> 定位：xlsx-r1 PLAN §1 C3 能力的**实证定谳**。用户指令 2：「calamine 与
> rust_xlsxwriter 不得被描述为具备已有工作簿可靠编辑往返能力；已有工作簿
> 修改及未触及内容保真须先做最小技术验证」。本文件 = 该最小技术验证的
> 全量记录。证据 = `spike/src/bin/fidelity.rs`（可复现，`cargo run --release
> --bin fidelity`）+ `spike/fixtures/fidelity_report.md`（机械产物）。

## 1. 验证设计

- **路径**：calamine 全量提取（表序/值矩阵/公式文本/合并范围 = calamine
  公开 API 的全部可观测面）→ 模拟修改（首表 (8,8) 写 `R1-MODIFIED`，
  各档数据区外统一位）→ rust_xlsxwriter **从零新建**重放全部提取面 + 修改
  → 与原档双重对比。
- **语义定性**：这是「读-改-重建」而非「读-改-写」。重建路径已重放
  calamine 能看到的**全部**可观测面（值 + 公式文本 + 缓存值 + 合并），
  即该组合（calamine 0.36.1 读 + rust_xlsxwriter 0.99.1 写）的**理论上限**。
  上限之内的丢失 = 组合的结构性丢失，非实现不尽力。
- **对比双层**：
  - 条目级——zip 条目名集合/内容字节对比（新增/丢失/变化/相同四分）；
  - 语义级——表序、值逐格（绝对坐标对齐）、公式文本、合并范围数、
    修改标记在位。

## 2. 语料

t10-b 五个正向维度档（构造意图与读侧校验见 `spike/fixtures/corpus/
manifest.md`）：dim1 公式（带/无缓存值）、dim2 样式（bold/红字/黄底/
边框/¥ 货币/百分比）、dim3 合并（三范围 + 散点值）、dim4 多表（四表 +
跨表公式）、dim5 关系引用（外链 URL×2 + 内部链接 + 纯文本 URL）。

## 3. 实测结果（2026-10-13，rust 1.99.0 / calamine 0.36.1 / rust_xlsxwriter 0.99.1 / zip 9.0.2）

### 3.1 语义级（未触及内容保真）

| 维度 | dim1 公式 | dim2 样式 | dim3 合并 | dim4 多表 | dim5 关系 | 判定 |
|------|-----------|-----------|-----------|-----------|-----------|------|
| 表序 | 保 | 保 | 保 | 保 | 保 | **5/5 保** |
| 值面（非空格逐格） | 9/9 | 6/6 | 4/4 | 13/13 | 5/5 | **37/37 保，0 差异** |
| 公式文本 | 4/4 | （无） | （无） | 2/2 | （无） | **6/6 保** |
| 合并范围 | 0→0 | 0→0 | 3→3 | 0→0 | 0→0 | **保** |
| 修改标记 (8,8) | 在位 | 在位 | 在位 | 在位 | 在位 | **5/5 在位** |

**值面细节**（含缓存值语义）：带缓存值公式格（dim1 ×2、dim4 ×2）经
`set_formula_result` 重放后值面零差异；无缓存值公式格（dim1 ×2）原档
读回即 `Float(0.0)`，重建后同为 0——两形态一致，但注意这**不能区分**
「缓存值恰为 0」与「无缓存值」（calamine 值面限制，登记不放大处理）。
`Data::Error` 格按字符串形态重放（`{e:?}`），错误码语义保留、类型面
降级（String 替代 Error）——本轮语料未含错误值格，登记为未覆盖面。

### 3.2 条目级（zip 条目四分）

| 档 | 原→新条目 | 相同 | 新增 | 丢失 | 变化 |
|----|-----------|------|------|------|------|
| dim1 | 9→10 | 5 | 1（sharedStrings.xml） | 0 | 4 |
| dim2 | 10→10 | 6 | 0 | 0 | 4（含 **styles.xml**） |
| dim3 | 10→10 | 6 | 0 | 0 | 4（含 styles.xml） |
| dim4 | 12→13 | 8 | 1（sharedStrings.xml） | 0 | 4 |
| dim5 | 12→11 | 6 | 0 | **1（xl/worksheets/_rels/sheet1.xml.rels）** | 5 |

条目级变化的语义解读（逐条定性，非机械结论）：

1. **sharedStrings 新增（dim1/dim4，良性）**：语料生成侧部分字符串走
   inline 存储，重建侧 rust_xlsxwriter 默认走 sharedStrings——字符串
   存储模式差异，值面已证零差异，非数据丢失。
2. **styles.xml 变化（dim2/dim3，结构性丢失的条目面证据）**：calamine
   无样式可观测面（Range 只含值），重建侧重写的是 rust_xlsxwriter 默认
   样式表——**原档 bold/红字/黄底/边框/¥ 货币/百分比格式全部丢失**。
   值仍在（6/6），显示语义不在。
3. **sheet1.xml.rels 丢失（dim5，结构性丢失的直接证据）**：超链接/
   关系部件在重建产物中**整体消失**——三个超链接格的可点击关系全部
   丢失（值面部分幸存：`write_url_with_text` 的文本值与纯文本 URL 串
   幸存为普通字符串；(0,0) 格 URL 文本幸存但链接语义丢失）。
4. **docProps/core.xml 变化（5/5 档，元数据搅动）**：创建器/时间戳
   差异——重建必然改写文档属性。属预期搅动，但意味着「未触及内容的
   字节级保真」在元数据面不成立。

## 4. 丢失矩阵（定谳）

| 未触及内容维度 | 保真状态 | 证据 |
|----------------|----------|------|
| 表序 | **保** | 5/5 档表名序列零差异 |
| 单元格值（含公式缓存值） | **保** | 37/37 非空格零差异 |
| 公式文本 | **保** | 6/6 条零文本差异（`_xlfn.` 前缀两侧一致） |
| 合并单元格范围 | **保** | 3→3 范围数与坐标保 |
| **单元格样式/格式** | **丢** | calamine 无可观测面 → 无法重放；styles.xml 整体重写 |
| **超链接/关系引用** | **丢** | sheet 级 .rels 部件整体消失（dim5 实测） |
| **文档元数据字节保真** | **丢（搅动）** | core.xml 5/5 档变化 |
| 列宽/行高/冻结窗格/打印设置等 sheet 级属性 | **丢（推断+部分实测）** | calamine 公开 API 未暴露（【推断】标注：未逐项实测，与样式同理不可重放） |

## 5. 结论（能力宣称边界，直进 CAPABILITIES.md）

1. **组合语义定谳**：calamine（读）+ rust_xlsxwriter（从零写）的
   「修改」= **全量重建**，不是原位修改。即使重放读侧全部可观测面
   （本轮已做，为理论上限），样式与关系引用仍结构性丢失。
2. **C3 宣称边界（本轮口径）**：
   - 可以宣称：「值/公式文本/合并范围/表序保真的重建式修改（已实测，
     丢失矩阵在档）」；
   - 不得宣称：「已有工作簿可靠编辑往返」「修改不影响未触及内容」；
   - 修改已有工作簿若含样式或超链接且需保真，**当前组合无解**——
     属数据丢失风险面，按用户指令 6 的暂停条件登记（不阻塞 C1/C2）。
3. **错误值格与无缓存值 0 歧义**：登记为未覆盖/不可区分面，C3 宣称
   语句不将其计入「保」。
