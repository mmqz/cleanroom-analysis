## 1. 能力宣称表

### C1 读取单元格数据（已验证，可宣称）

**宣称语**：读取 XLSX 工作簿的表结构（表名与顺序）、单元格值矩阵
（字符串/数字/布尔/日期/错误值，含公式缓存值）、公式文本、合并单元
格范围。读取前经容器预扫门（声明尺寸求和/单条目/条目数/路径逃逸
四检查），敌意输入 typed reject 零 panic。

**证据**：
- 7 维语料正向 5 维 + 对照件全过（read_proto 17/17，锚点断言含
  表序/非空格数/公式数/合并数逐档对账）；
- 量级：T3 探针 50 万格 139ms、156,000 格零丢失全量对账；
- 敌意 11 件三分归类钉定：拒绝 3 / 解析错误 6 / 容忍 2（容忍度
  发现见 §3）。

**边界（不宣称）**：
- 样式/格式面（calamine 无可观测 API——FIDELITY §4）；
- 超链接/关系引用面（同上）；
- 图表/透视表/图片部件（未测，不在四 API 面）；
- 公式**求值**（只读缓存值与文本，无计算引擎——T4 威胁面随公式
  引擎立项）；
- docx/xlsx 以外格式（xls/xlsm/ods 未在本轮语料，calamine 支持
  面未验证不宣称）。

### C2 新建 XLSX（已验证，可宣称）

**宣称语**：从零新建 XLSX 工作簿：多工作表、字符串/数字/布尔值、
公式（含跨表引用与缓存值）、合并单元格、超链接（外部 URL 与内部
表引用）。大表流式写（constant_memory）。

**证据**：
- 语料生成侧 = rust_xlsxwriter，五维正向件全部被 calamine 读回
  校验（写读互证，manifest 逐件锚点）；
- 量级：100 万格 972ms / 产物 3.33MB / 重开往返对账（T3 探针）；
- 消费面：值/公式/合并经 fidelity 重建路径重放后 37/37 格零差异。

**边界（不宣称）**：
- 样式写入正确性 = **XML 级验证**（style_probe 探针 9/9：bold/
  FF0000 字色/FFFF00 填充/thin 边框/¥ 与百分比自定义 numFmt/
  cellXfs 应用链；2026-10-13 闭项）；完整样式模型（条件格式/
  主题色/富文本内联样式）未验证不宣称；
- 修改已有工作簿（见 C3）。

### C3 修改已有工作簿（**不宣称支持**——结构性限制在档）

**宣称语（唯一允许的口径）**：不提供已有工作簿的编辑往返能力。
已知替代路径为「读-改-重建」（calamine 提取 → rust_xlsxwriter
从零新建），该路径的实测保真边界：**保** = 表序/值（含缓存值）/
公式文本/合并范围；**丢** = 单元格样式与格式、超链接与关系引用、
元数据字节保真（FIDELITY.md §4 丢失矩阵，五档实测）。

**定性**：该丢失为 calamine（无样式/关系可观测面）+ rust_xlsxwriter
（从零写器）组合的**结构性限制**，非实现缺陷、非尽力不足（重建
路径已重放读侧全部可观测面 = 理论上限）。含样式或超链接且需保真
的已有工作簿修改 = **数据丢失风险面**（用户指令 6 暂停条件之一）
——此场景明确告知用户不支持，不静默降级。

## 2. DOCX 独立模块边界声明（用户指令 5）

1. DOCX 读写为**独立模块**（后续按实际需求接入），与 XLSX 模块
   **不共用领域模型、不建统一 Office 接口抽象**。
2. 现有 mdc-office crate 内的共享面仅限**消毒五面**（上下文级纯
   函数：CSV/XML 字符/XML 实体/HTML/域白名单——上下文语义与格式
   无关，csv_formula_guard 的 xlsx 路线豁免注记为形态差异的唯一
   例外），非领域模型耦合。
3. 不为「统一接口」预设计：t10-e 新增的 url_policy 同样是上下文
   纯函数（跨格式复用正当）；工作簿/文档对象模型、IO 管线、错误
   面均按格式独立演进。
4. ADR-O1 O1-6（docx 渲染级读侧）维持开放裁决，本轮零触碰。

## 3. 容忍度发现登记（t10-d 实证，随宣称发布）

1. **0x00 读侧容忍**（mal7c）：XML 1.0 非法控制字符在文本位被
   解析器容忍，值含 NUL 落内存——**读侧不过滤**；再输出时消毒链
   （xml_control_chars）为必经路径（SANITIZE_TESTS.md §8 联动）。
2. **垃圾部件静默降级**（mal7e）：非 XML 二进制部件被容忍，提取
   为空表（无错误信号）——登记为已知行为；严格模式属后续裁决。
3. **谎言头分层**（mal6a）：声明 16B 实际 1MB 的条目在 calamine
   语义层先报错（缺部件），未触达 zip 读界拒绝路径——分层防线
   中语义层先拦；zip 读界行为以 8.6 对齐重测为准（DEPS.md §1）。
